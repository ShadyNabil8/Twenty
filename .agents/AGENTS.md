# Agent Rules — Eye 20-20-20

Project-scoped rules for AI coding agents working in this repository.
`CLAUDE.md` at the repo root is the primary guide (commands, architecture,
style, safety invariants) — read it first. This file adds workflow rules.

## Workflow

1. **Verification-first.** No change is "done" until
   `npm run typecheck && npm run lint && npm test && npm run smoke` all pass.
   The smoke test launches the real app and flashes translucent overlays for a
   few seconds on the local machine — that is expected and by design.
2. **Never run the app with a live mouse jail unattended.** Real-jail testing
   (no `EYE2020_SMOKE`) freezes the user's cursor; leave that to the human via
   the manual checklist in `.claude/skills/verify/SKILL.md`. Agent-driven runs
   must set `EYE2020_SMOKE=1` (and usually `EYE2020_FAST=1`).
3. **IDE environments:** strip `ELECTRON_RUN_AS_NODE` from the environment for
   any process that must run as a real Electron app.
4. Timer or settings behavior changes require a matching unit test in `tests/`.
5. Do not commit, push, or publish unless the user explicitly asks.

## Platform code

- Development happens on Windows; macOS/Linux code paths cannot be executed
  here. Keep them defensive: guarded by `process.platform`, wrapped in
  try/catch, degrading to a logging noop — never crash the app because a
  platform API is missing (e.g. Wayland has no global pointer grabs).
- Anything platform-specific belongs in `src/main/native/` behind the
  `MouseJail` interface. Do not scatter `process.platform` checks elsewhere
  (the few in `index.ts`/`tray.ts` for icons and login items are the allowed
  exceptions).

## Dependencies

Runtime: **koffi only**. Dev: electron, electron-vite, electron-builder,
typescript, vitest, eslint(+typescript-eslint), prettier, cross-env.
Do not add UI frameworks, robotjs, or anything needing node-gyp. Icons are
generated by `scripts/gen-icons.mjs` (pure Node) — no binary assets in git.

## Skills & tools

- `.claude/skills/run/SKILL.md` — how to launch and drive the app for testing.
- `.claude/skills/verify/SKILL.md` — full verification recipe + manual checklist.
- `.claude/skills/release/SKILL.md` — packaging installers per platform.
- `scripts/probe-jail-win32.mjs` — validate the ClipCursor FFI path without
  disturbing the user's cursor.

(Skills live under `.claude/skills/` — where Claude Code auto-discovers them —
rather than `.agents/skills/`.)
